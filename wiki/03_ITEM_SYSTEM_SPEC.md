# 03. 아이템 & 물리 시스템 명세 (Item System Specification)

## 2. 체크포인트 및 아이템 상자 스폰 알고리즘

- 트랙 전체 길이(`totalDistance`)의 **20%, 40%, 60%, 80%** 지점에 전 레인에 걸쳐 아이템 상자(`🎁`)가 스폰됩니다.
- 말이 상자 중심 기준 `±25m` 반경에 도달하면 `collected = true`로 변경되며 파티클 폭발 효과와 함께 순위 가중치 기반으로 아이템이 인벤토리에 지급됩니다.

```javascript
// 순위별 드랍 가중치 규칙 (결정론적 RNG 기반)
if (horse.rank === 1) {
  possibleItems = [BANANA, SHIELD, BOOSTER, ESPRESSO];
} else if (horse.rank >= totalHorses - 1) {
  possibleItems = [BOOSTER, LIGHTNING, MAGNET, MISSILE, APPROVAL, ESPRESSO]; // 역전용 강력 아이템
} else {
  possibleItems = [BOOSTER, BANANA, SHIELD, LIGHTNING, MISSILE, MAGNET, ESPRESSO, APPROVAL];
}
```

## 3. 다중 레인(Multi-Lane) 바나나 & 결재서류 타겟팅 로직

1. **🍌 바나나**:
   - 던지는 말(`horse`)을 뒤쫓는 살아있는 말들을 거리순(`b.distance - a.distance`)으로 정렬합니다.
   - 가장 근접한 1순위 추격자의 `target1.lane`에 `dropDistance = target1.distance + 35m` 위치로 바나나 오브젝트를 생성합니다.
   - 2명 이상의 추격자가 있을 경우 60% 확률로 2순위 추격자 레인에도 보너스 바나나를 매설합니다.
   - 만약 던지는 말이 최하위(꼴찌)인 경우, 바로 앞 선두 주자의 진행 레인 전방 45m 지점에 역전용 함정을 투척합니다.
2. **📋 긴급 결재서류**:
   - 자신보다 앞서 달리는 말 중 가장 가까운 앞 순위 말(또는 선두)을 타겟으로 지정해 서류 투사체를 날립니다.

## 4. 피격 & 방어 판정 매트릭스 (Defense Matrix)

| 공격 아이템 | 일반 상태 피격 효과 | 🛡️ 쉴드 활성화 상태 |
| :--- | :--- | :--- |
| 🍌 **바나나** | `state = 'slip'`, 360도 스핀, 속도 35%로 다운 (1.6s) | **쉴드 파괴 (방어 성공)**, 미끄러짐 없음 |
| 🎯 **미사일** | `state = 'slip'`, 폭발 이펙트, 속도 30%로 다운 (1.8s) | **쉴드 파괴 (방어 성공)**, 피격 스턴 없음 |
| ⚡️ **번개** | `state = 'slip'`, 전기 스파크, 속도 40%로 다운 (1.5s) | **쉴드 파괴 (방어 성공)**, 감전 없음 |
| 📋 **결재서류** | `state = 'slip'`, 서류 더미 경직, 속도 38%로 다운 (1.5s) | **쉴드 파괴 (방어 성공)**, 결재 반려 |
