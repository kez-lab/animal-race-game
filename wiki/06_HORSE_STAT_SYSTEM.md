# 06. 경주마 5대 능력치 및 마구간 드래프트 명세 (Horse Stat & Draft Specification)

## 1. 스탯 밸런스 예산 시스템 (350-Point Zero-Sum Budget)

오피스 더비의 모든 경주마는 사기(OP) 캐릭터의 등장을 방지하고 공정한 승부를 보장하기 위해 **총합 350 포인트 (평균 70pt)**의 스탯 예산 내에서 특화되도록 수학적으로 정규화됩니다.

```
       [ 5대 핵심 능력치 다이어그램 ]
                 ⚡️ 최고속도 (Speed: 50~90)
                     /        \
   🚀 가속력 (50~90)  - (350pt) - 🔋 지구력 (50~90)
                     \        /
       🍀 행운 (50~90)  -   🧠 지능 (50~90)
```

### 1) 5대 스탯 정의 및 물리 엔진 반영 공식

| 능력치 | 범위 | 물리 공식 및 게임 영향 |
| :--- | :--- | :--- |
| **⚡️ 최고속도 (Speed)** | 50 ~ 90 | `baseSpeed * (0.85 + 0.3 * (speed / 100))`<br>최고 직진 속도를 0.95배 ~ 1.12배 범위로 결정 |
| **🚀 가속력 (Acceleration)** | 50 ~ 90 | `lerpSpeed = 3.5 * (0.7 + 0.6 * (accel / 100))`<br>출발 총성 후 도달 시간 및 바나나/미사일 피격 후 회복 탄력성 결정 |
| **🔋 지구력 (Stamina)** | 50 ~ 90 | `staminaDrain = 3.0 * (1.3 - 0.6 * (stamina / 100))`<br>초기 스태미나 총량(85~120) 및 막판 칼퇴 스퍼트 지속 시간 결정 |
| **🍀 행운 (Luck)** | 50 ~ 90 | 아이템 박스 획득 시 1등급 강력 역전 아이템(부스터, 번개, 자석) 획득 가중치 부여 |
| **🧠 지능 (Intellect)** | 50 ~ 90 | 온디바이스 AI의 위기 감지 및 0.1초 쉴드 방어 반응 지연 시간 단축 |

## 3. 온디바이스 AI 즉석 분양 알고리즘 (`HorseGenerator.generateAIHorse`)

1. 6대 아키타입 중 하나를 무작위 선택하거나 사용자가 지정
2. 아키타입 가중치에 ±4의 무작위 노이즈 부여
3. `normalizeStatsToBudget()` 알고리즘을 통해 **오차 0pt로 350pt 예산에 정확히 Zero-Sum 수렴**
4. 온디바이스 AI가 사내 분위기(칼퇴, 탕비실, 커피, 월급)에 맞는 유쾌한 이명(Title)과 스토리(Lore) 결합
